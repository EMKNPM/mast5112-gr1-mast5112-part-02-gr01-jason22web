# Chef Menu Manager App 🍳

Welcome to the **Chef Menu Manager App**, developed as part of the MAST5112 module project. This application is designed to help chefs and kitchen managers efficiently create, organize, and manage culinary menus, dishes, and ingredients.

---

## 🚀 Features

* **Menu Creation & Management:** Easily add, edit, and organize daily or seasonal menus.
* **Dish Customization:** Manage individual dishes, including descriptions, categories, and pricing.
* **Ingredient Tracking:** Keep track of components and elements associated with each dish.
* **Responsive UI:** Built with modern web technologies for a seamless desktop and mobile experience.

---

## 🛠️ Tech Stack

This project is built using modern web standards and strongly typed code:
* **TypeScript:** ~86.6% (Core logic and components)
* **JavaScript:** ~11.6% 
* **CSS:** ~1.8% (Styling and layout)
